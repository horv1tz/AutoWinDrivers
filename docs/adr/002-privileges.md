# ADR-002. Модель прав: UI без администратора, отдельный привилегированный воркер

**Статус:** принято, 2026-10-24.

## Контекст

Перечисление устройств и поиск драйверов не требуют прав администратора.
Установка драйверов, точки восстановления и экспорт из DriverStore — требуют.
Фоновый агент должен работать постоянно и не должен висеть под администратором.

## Решение

- Desktop-приложение и трей-агент запускаются с правами пользователя.
- Привилегированные операции выполняет отдельный процесс `awd-worker`, который UI запускает через
  `ShellExecuteExW("runas")` при первой необходимости в сессии и держит живым до выхода.
- Общение UI ↔ воркер — именованный канал с JSON-RPC (`awd-ipc`), доступ к каналу ограничен
  текущим пользователем через DACL; воркер проверяет каждое задание и выполняет только операции
  из белого списка (download в свой каталог, verify, install, backup, restore point).
- Автозапуск агента — задача Планировщика «при входе пользователя» без повышенных прав.

## Промежуточный этап

До конца этапа 3 допускается манифест `requireAdministrator` на CLI для отладки установки.
Разделение на воркер — обязательное условие релиза (этап 6).

## Последствия

- Одно окно UAC на сессию вместо одного на действие.
- Дополнительный крейт и протокол, но все привилегированные пути сосредоточены в одном месте.
