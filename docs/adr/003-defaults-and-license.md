# ADR-003. Лицензия и политики по умолчанию

**Статус:** принято, 2026-10-24 (по решению владельца проекта).

## Лицензия

Проект открытый, двойная лицензия **MIT OR Apache-2.0** (стандарт экосистемы Rust):
`LICENSE-MIT`, `LICENSE-APACHE`, поле `license = "MIT OR Apache-2.0"` во всех крейтах.
Зависимости проверяются `cargo deny` по списку разрешённых открытых лицензий.

## Агент мониторинга

Агент — по желанию пользователя: по умолчанию **выключен**, предлагается включить при первом запуске
и в настройках. При включённом агенте политика по умолчанию — **«Спрашивать»**
(уведомление с кнопкой «Установить»); автоматическая установка только WHQL-драйверов из Windows Update
доступна как явный выбор пользователя.

## Телеметрия

**Без телеметрии и крэш-репортов.** Никаких сетевых запросов, кроме обращений к источникам драйверов
и проверки обновлений приложения. Диагностика (логи + обезличенный дамп устройств) собирается
локально кнопкой «Собрать диагностику», отправляет её пользователь сам.

## Офлайн-драйверпаки

В v1 не входят. Модель провайдеров оставляет для них место (этап 7).
